# Final Demo Test Checklist

Before presenting, check each item:

- [ ] `index.html` opens in Chrome or Edge.
- [ ] Dashboard loads without a blank screen.
- [ ] Add expense form saves a sample expense.
- [ ] Expense appears on Dashboard and Expenses page.
- [ ] Search and category filter work.
- [ ] Delete expense works.
- [ ] Monthly budget can be changed.
- [ ] Progress bar and remaining amount update.
- [ ] Savings goal can be created.
- [ ] Add ₹100 updates goal progress.
- [ ] Insights chart appears after adding expenses (internet required for Chart.js CDN).
- [ ] Assistant answers “How much is left?”
- [ ] Refresh page; expenses and goals remain saved.
- [ ] Browser zoom is set to 90–100% for presentation.
- [ ] Close unnecessary tabs and notifications before screen-sharing.

## Suggested sample entries
- Lunch — ₹120 — Food
- Bus pass — ₹300 — Travel
- Notebook — ₹85 — Education
- Coffee — ₹60 — Food
- Movie — ₹180 — Entertainment

## If something looks wrong
- Make sure all four files are in the same folder: `index.html`, `style.css`, `app.js`, `README.md`.
- Refresh the browser after saving code changes.
- If the chart is missing, check internet connection; the rest of the app should still work.
- Use Chrome or Microsoft Edge for the demo.
